# NEPU Scholarship Score Explorer

东油石油工程学院研究生综测分数可视化工具。依据《石油工程学院研究生学业奖学金评定办法及细则（修订）》，可选择培养类型和年级，逐项记录成绩、活动与成果，查看各项上限和预计总分。

**在线使用：** [https://seaout.github.io/nepu-scholarship-score/](https://seaout.github.io/nepu-scholarship-score/)

## 为什么做这个工具

学院的学业奖学金评分细则涉及课程、德育、文体、论文、专利、竞赛等多类项目。研二与研三、学硕与专硕的项目上限也不同。对照表格逐条估算时，很难直观看到某项成果计入后会给总分带来多少变化，哪些分数又被子项或大项上限截掉。

这个单文件页面把细则拆成可选择的项目：输入符合条件的成绩或成果后，按内置规则估算分数，并用100分长条展示各部分的权重与当前得分。它适合整理自己的材料和预估综测分数，**不是学院的正式评分系统，也不预测奖学金名额或排名**。

## 能做什么

* 切换研二、研三及学硕、专硕四套模板；点击长条查看分项和上限。

* 记录课程与外语成绩；给论文、专利、软著、竞赛和学术交流逐项添加名称、类型与认定状态。

* 在“德育及文化体育”下分别填写德育素质，以及文艺、体育、荣誉称号和媒体撰稿记录。

* 按细则估算单项得分，并处理实用新型、软著、数学建模、文艺与体育等子项上限和各大项上限；同名专利的公开、授权阶段不重复累计。

* 自动保存到当前浏览器；支持导出 JSON 数据备份，并在需要时导入。

* 提供高级 JSON 配置入口，可自定义项目名称和权重。自定义项目采用手动记分。

## 使用方法

1. 打开上方在线地址，或下载仓库根目录的 **index.html** 后直接用浏览器打开。

2. 选择评分模板，点击分数长条中的项目。

3. 添加成果或活动，填写名称、分区或奖项等信息。确认符合细则中的署名、单位、状态和证明材料要求后，勾选“满足认定条件”，该记录才计入估算。

4. 查看总分与各分项。换浏览器、换设备或准备长期保存时，点击“下载数据备份”；之后可用“导入备份”恢复。

记录默认只保存在当前浏览器本地，浏览器清除站点数据后可能丢失本地记录，请自行保存备份。

## 计分说明

内置依据《石油工程学院研究生学业奖学金评定办法及细则（修订）》整理。工具仅计算录入且标为符合认定条件的项目；成果是否有效、细则如何解释及最终分数，均以学院当年通知和审核结果为准。若学院修订细则，应核对代码中的分值后再估算。
